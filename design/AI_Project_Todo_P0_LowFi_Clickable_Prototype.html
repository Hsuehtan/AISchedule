AI 项目待办 P0 低保真原型

这是基于当前 P0 范围整理的可点击预览。它不是开发版本，只用于评审页面结构和核心交互链路。

核心链路

  • 账号密码登录
  • 全部/项目待办列表
  • 文字输入与语音输入
  • Agent 确认卡片 / 直接执行 / 候选选择
  • 待办编辑、完成折叠、软删除
  • 项目新建、改名、归档

快速触发

评审重点

  • 无项目待办只在“全部”显示。
  • 完成后沉底，并进入折叠区。
  • 语音先转文字，再进入同一 Agent 逻辑。
  • 批量创建必须确认，明确单项操作可直接执行并撤销。
