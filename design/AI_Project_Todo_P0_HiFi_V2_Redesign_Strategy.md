# AI 项目待办 P0 高保真 UI V2 重设计策略

## 为什么重做

V1 的问题不是细节，而是设计方法错了：它基本沿着低保真线框逐项上色，缺少产品气质、视觉记忆点和真实移动端的信息层级。

V2 不再把低保真当作版式稿，而是只保留它定义的 P0 交互边界：

- 登录
- 项目筛选
- 待办列表
- 文字 / 语音输入
- AI 建议确认
- 项目管理
- 撤销与状态反馈

## V2 设计方向

关键词：**Smart Inbox / 今日编排 / 轻量项目面板 / 可执行 AI 建议**

这版更像一个“会帮你整理的待办收件箱”，而不是普通 Todo List 加一个 AI 按钮。

- 首页顶部从普通标题改为“今天需要处理什么”的工作台状态。
- 项目不只是 tabs，而是带颜色和数量的项目轨道。
- 任务卡片从白卡片列表改为时间块 + 项目色条 + 状态徽标，提升扫描效率。
- AI 输入入口从普通输入框改为底部 command composer，强调“说一句话，让系统处理”。
- AI 建议 sheet 做成可确认的计划草稿，而不是字段列表。
- 项目管理 sheet 做成轻量项目控制台，有状态、数量、归档入口。

## 视觉语言

- 背景不使用单调蓝白，改为暖灰纸感 `#F3F0EA` 与墨色 `#181A1F` 的反差。
- 主品牌色为活力绿 `#B7F36B`，只用于 AI 行动和关键状态，不铺满全屏。
- 项目色使用番茄、靛蓝、湖蓝、绿四组，形成可识别的任务归属。
- 卡片更少、更清楚：重复项才用卡片，页面主体保留留白与分区。
- 图标全部使用导入 SVG 节点，不用 emoji 充当 UI 图标。

## 覆盖画板

1. `V2 / Login`
2. `V2 / Today Inbox`
3. `V2 / AI Plan Sheet`
4. `V2 / Project Console`

## 与低保真的关系

V2 不是改变 P0 范围，而是重新解释 P0：

- “全部 / 工作 / 生活 / 孩子上学 / 面试准备”仍存在，但视觉表现更像项目轨道。
- 无项目待办仍在“全部”中可见。
- 完成项仍沉底折叠。
- 语音和文字仍进入同一 Agent 逻辑。
- 批量创建仍必须确认。
- 项目仍支持新建、改名、归档。
