# 2026-10-26 登录首页 IP 与操作间距

依据用户提供的 IP 姿态参考和登录页截图实施。正式登录、注册共用更新，H1 历史原型保持原样。

## 本次变更

- 标题由“把杂事收进今天”改为“把杂事装进来”。
- 对勾替换为参考形象的透明 PNG 双表情素材（1774×887，约 1.1 MB，带 alpha），由内置 imagegen 生成。来源记录见 `apps/client/src/assets/mascot/README.md`。
- 6 秒循环：轻微上下漂浮和左右摆动，睁眼/弯眼微笑柔和交替；首尾姿态一致。只使用 CSS transform/opacity，无动画库或业务请求。
- 点击 IP 或 Enter/Space 可暂停/恢复，动画不承载业务含义。`prefers-reduced-motion: reduce` 显示静态睁眼形象并移除无效暂停入口的键盘焦点。
- 主按钮上方间距 16 个物理 CSS px；登录/注册切换按钮间距 12px，保持真实 44px 热区。短视口沿用原页面滚动，不改变校验、认证或提交逻辑。
