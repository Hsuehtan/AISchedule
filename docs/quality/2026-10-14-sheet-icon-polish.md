# 2026-10-14 浮层与图标细化

按用户本轮三张标注图实施，局部视觉决策覆盖上一轮固定计划高度。

- 计划草稿关闭按钮移除 Taro 默认 `::after` 边框，保留 44px 热区、可访问名称和焦点轮廓。
- 列表“编辑”按钮使用 flex 垂直/水平居中，点击范围不缩小。
- 计划列表和编辑状态均使用内容高度，最大高度受 90dvh/760px 限制；长列表内部滚动，编辑操作在滚动区底部保持可达。取消撑满高度与绝对定位导致的空白。
- 首页移除键盘按钮；直接点击输入框编辑，首字切换发送及麦克风原有入口保持不变。
- 文件夹、时钟、麦克风使用 Lucide 官方 SVG，并通过 CSS mask 应用产品颜色；仅本地打包三个文件，无 CDN、运行时请求或新增图标依赖。
