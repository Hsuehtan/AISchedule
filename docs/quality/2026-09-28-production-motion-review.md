# 正式产品 UX 动效专项

日期：2026-09-28。范围为正式 H5 首页及其任务、项目、Agent 弹层；以 Figma Production V3 `229:2` 的静止画面为对照。H1 Fixture 不启用正式页动效。T24 人工审查与 H3 状态不变。

## 动效规格

| 操作                        | 表现                                                       | 不变的交互约束                                                            |
| --------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------- |
| 按钮按下                    | 内容缩至 0.98，按下 80ms，松开 120ms                       | 外层热区、配色、焦点轮廓及禁用规则不变                                    |
| Bottom Sheet / Agent Dialog | 进场上移 16px、淡入 220ms；退场下移 8px、淡出 160ms        | 业务关闭和焦点恢复立即生效；退场副本 `inert`、`aria-hidden`，不可触发操作 |
| Smart Inbox / 已完成区      | 高度和内容透明度过渡 200ms                                 | 折叠后内容立即退出 Tab 顺序；展开状态立即更新                             |
| 待办列表                    | 新项上移 6px、淡入 180ms；离场淡出 120ms；剩余行归位 180ms | 只在服务端数据确认后、任务 ID 集合或顺序变化时触发；离场副本不可操作      |
| 项目筛选                    | 新结果淡入 140ms                                           | 查询与筛选状态即时切换                                                    |
| Agent 新消息、草稿及错误    | 新消息上移 6px、淡入 180ms；现有错误与草稿内容淡入 120ms   | 历史消息重开不逐条重播；不模拟模型进度                                    |
| 删除撤销提示                | 上移 6px、淡入 120ms                                       | 服务端 `expiresAt` 仍决定 3 秒撤销可用期                                  |

进入与归位缓动为 `cubic-bezier(0.2, 0, 0, 1)`，退场为 ease-in。`prefers-reduced-motion: reduce` 下动效时长归零；非 H5 环境即时呈现。

## 实现与验收边界

- 共享 UI 增加动效变量，只有正式产品页面启用按压和弹层规则。按压缩放只作用于按钮内部视觉内容，外层布局和点击区域不变。
- 弹层退场使用无事件、不可聚焦的 DOM 副本；原 React 弹层和焦点约束在业务关闭时同步解除。连续打开另一个弹层时，新弹层保持最高层级。
- 任务列表的视觉变化依据稳定任务 ID，首次数据加载不逐项播放；最后一项离场后，空状态立即出现。
- 不新增接口、数据库字段、Agent Action、确认路径、撤销能力或首次引导。
