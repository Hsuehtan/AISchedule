# 2026-10-14 浮层拖动与内部滚动

依据用户本轮标注图，将共享浮层灰色横线升级为可调整高度的手柄。

## 行为

- 正式 H5 BottomSheet/Dialog 共用 `manageModalInteraction`，由原共享视口适配入口挂载。鼠标及触屏通过 Pointer Events 调整高度，下边缘固定，上拖增高、下拖缩小；不触发关闭或业务请求。
- 可操作手柄为 88×44px，灰线保持 44×4px。标题从手柄操作区下方开始，避免拖动热区与标题重叠。
- 最大高度受 760px、可用视口及容器边界限制；最小高度依据原内容高度、标题和内部固定摘要/操作区计算，保留可滚动内容空间；计划底部操作和对话输入不会因向下拖动而被挤出。
- 只在拖动后固定用户选择的高度；关闭重开或切换浮层标题状态时恢复内容自适应。键盘方向键每次调整 40px，PageUp/Down 100px，Home/End 到边界，Enter 恢复自适应。
- 手柄进入 Tab 顺序，具有 slider 名称和当前高度，保留原输入/按钮初始焦点。捕获丢失、pointercancel、窗口失焦或卸载均终止拖动并释放监听，不关闭浮层。
- 所有正式浮层内部滚动容器（包括长列表、编辑区、对话消息和文本区）隐藏原生滚动条，保留 wheel、触屏和键盘滚动。手柄之外不禁用触屏默认滚动。
- H1 历史原型及非 DOM 环境保持装饰性手柄。API、业务确认和计费不变。

## 验证

测试使用本地隔离服务（H5 11106 / API 13020 / Agent Stub 14021）、合成账号和 Agent Stub，不使用真实用户数据。

- 失败先行：新增拖动 E2E 首次运行因缺少高度手柄失败，再实现共享控制器。
- 客户端与共享 UI 单元测试：89 + 11 项通过。
- 客户端与共享 UI `typecheck`、`lint` 以及 E2E ESLint 通过。
- E2E 启动前的客户端及依赖 `build` 通过。
- 首轮完整 E2E：37/38；项目栏测试在 320 → 390px 切换后读到了旧 rem 尺寸（36.0938px），补上响应式尺寸就绪等待，不修改产品项目栏样式。最终复验结果见下。
- 新增鼠标拖动、触屏拖动及 pointercancel、隐藏滚动条且可滚动、键盘调高、关闭复位、四视口边界和 axe；原页面优化用例额外覆盖计划/编辑浮层缩到最小时按钮仍可见。

最终完整回归：38/38 通过，包含正式输入、Phase 2、Phase 3、焦点隔离/恢复、减少动态效果及 H1 原型回归。
