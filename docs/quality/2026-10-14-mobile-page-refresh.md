# 2026-10-14 正式 H5 页面优化

本次依据用户提供的五张参考图，覆盖此前 Production V3 的对应布局；实施前读取了 Figma `dryFtYbit291732gktHIqZ` 的 `229:2` 当前结构。网页不复制浏览器标题栏、IP 地址或系统底部横条。

## 实现

- 登录页移除静态黑色演示卡，登录框随正常文档流上移。
- 首页标题增加辅助文案，任务卡改为上方标题、下方项目和时间；保留优先级点与完成入口。项目选项图标打开现有项目管理。
- 底部白色输入框直接编辑；输入首字后麦克风替换为发送，清空恢复。发送按钮使用淡入动画，外层始终保持 44px 热区；减少动态效果时关闭动画。仅点击发送提交，空白禁用，不绑定 Enter，避免输入法确认误发送。
- 首页发送复用现有 Agent 轮次 API、幂等键和提交锁；失败保留文本，成功仅清除本次提交的文本。Smart Inbox 的开始对话入口直接聚焦首页输入。
- 计划草稿保留摘要、独立滚动列表与底部取消/重生成/创建操作。编辑单项时标题为“编辑草稿”，隐藏列表操作，仅显示保存和返回；保存成功回列表，返回不保存。保存失败仍停在编辑区并保留输入。
- 已有待办使用“编辑待办”，底部仅删除与保存；新建待办仍保留取消与保存。字段使用左侧标签和右侧控件，优先级使用分段选择。
