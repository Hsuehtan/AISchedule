# 首页内容、历史删除与四档优先级验收

日期：2026-10-27。按用户本轮明确产品决策实施；T24 待审状态不变。

## 实现

- 有实际 Agent 内容的首页卡片隐藏 Smart Inbox 标题，正文最多三行省略，操作按钮独立排布，避免长正文被固定高度裁切；空态仍保留标题。完整内容从原操作入口查看。
- 历史记录长按 550ms 打开删除确认，位移超过 8px、滚动、取消手势终止长按；支持右键、Delete 和 Shift+F10。正常短按仍进入原会话。确认失败保留重试，重复提交加锁。
- 删除采用服务端 `historyDeletedAt` 软删除，刷新后仍从历史列表隐藏；会话内容、已创建待办、待确认提案和积分不受影响，确认页明确说明。接口按当前账号鉴权，越权返回 404，重复删除幂等。
- 优先级 HIGH/MEDIUM/LOW/NONE 分别为红/黄/绿/灰；无优先级选项显示“无”，可访问名称“无优先级”。覆盖手工编辑、计划编辑、确认落库、Node/Python 契约和数据库枚举；新任务默认仍为 MEDIUM。
- 两项增量迁移已在隔离库及本地开发库应用。未操作公网环境，未删除现有业务数据。
