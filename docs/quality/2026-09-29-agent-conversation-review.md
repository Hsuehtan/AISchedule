# 正式 Agent 对话浮层修正验收

日期：2026-09-29。对照 Figma Production V3 `229:2` 与 PRD 4.7，范围为正式 H5 对话浮层；T24 人工审查门禁保持待审。

## 修正结果

- 标题留在顶部、消息区独立滚动、文字输入和发送按钮固定在底部。390×560 压缩视口下输入仍可见；监听 `visualViewport` 的高度和偏移，让键盘收缩可用区域时优先缩小消息区。
- 候选按钮使用项目的 12px/18px 正文字号与常规字重，清理 Taro 默认按钮边框；保留白底、细边框和至少 44px 热区。禁用发送态使用既有 Screen/Muted 色，axe 对比度检查通过。
- 同一浮层的普通追问沿用 `conversationId`；最新待回答问题的自由文本走原回答接口，候选按钮继续走原选项接口。“都不是，补充说明”聚焦底部输入。处理中可继续编辑草稿，发送入口禁用；请求成功只清除本次草稿，冲突后刷新问题并保留文本。
- 已关闭或切换的浮层不会因本次文本提交结果重新打开。没有新增公开 API、数据表、Agent 协议或写入确认路径。
