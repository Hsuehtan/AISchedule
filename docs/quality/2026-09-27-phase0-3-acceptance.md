## 缺陷、复现与影响

### D01 — H1 文本输入实际热区不足（产品缺陷，P2）

- 依据：T09/计划规定交互目标不少于 44 CSS px。
- 复现：打开隔离 Gallery `/#/pages/review/index?screen=text-input`，测量 `taro-textarea-core`，再点击 `.commandInput` 可见外框左上 5px。
- 预期：输入控件至少 44×44；点击可见输入区即聚焦。
- 实际：core 约 30×43；原生 textarea 未聚焦。完整 E2E 与临时点击探针均失败，见 E05/E06 和[截图](screenshots/acceptance-2026-09-27-h1-hit-target-failure.png)。正式 Phase 3 输入区的三视口 44px 用例通过，因此影响目前定位为 H1 Gallery；仍违反 T09 验收条件。
- 建议：扩大真实可点击/可聚焦的输入层而非仅放大外框；补充边缘点击回归。已批准延期的纯视觉细节不在此项内。

### D02 — 两个数据库集成夹具日期失效（测试缺陷，P1 门禁）

- 依据：所有 DB 集成测试在当前日期应可重跑；CandidateRef/Proposal 到期值必须晚于创建时间。
- 复现：原始基线执行 `pnpm test:integration`；`packages/db/test/agent-schema.integration.test.ts:283` 与 `:475` 分别固定 `2026-07-17` 和 `2026-07-24`，运行日为 2026-09-27。
- 预期：有效夹具可建表记录，随后验证租户、Mutation 和单执行约束。
